# Smruthi Sundar Portfolio

A responsive personal portfolio built with React, Vite, and Tailwind CSS. It presents selected projects, professional experience, education, skills, and contact links.

## Getting Started

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Scripts

- `npm run dev` starts the development server.
- `npm run build` creates the production build in `dist/`.
- `npm run preview` serves the production build locally after running the build command.

## Project Structure

- `src/App.jsx` composes the page sections.
- `src/components/` contains the page sections and shared UI components.
- `src/data.js` contains the portfolio content.
- `src/styles.css` loads Tailwind CSS.
- `vite.config.js` configures React and Tailwind for Vite.
